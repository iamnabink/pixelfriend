# Changelog

## 0.3.0

- New default avatar: a 2D cartoon character who raises a hand and says "Hi, do you have water?" with lip-sync
- `pixelfriend.avatar.style` chooses between the cartoon character and the pixel buddy
- Colors default to the hoodie palette and apply to both avatars
- Heartbeat in the state file and `command.json` handling so Activ can answer reminders

## 0.2.0

- Reminder defaults to every 60 minutes and asks "Did you have water?"
- State file now carries avatar colors and sprite config so Activ's desktop buddy matches

## 0.1.0

- Hydration reminders with YES / Remind me later
- Walking pixel buddy in the sidebar and editor
- Wave + dance celebration with "Nice!" bubble
- Status bar countdown
- Settings page (interval, snooze, sounds, avatar colors/size/speed)
- Custom PNG sprite sheets
- Shared state file for the Activ menu bar app
